# Stellar Plugin Repo

Regional Dalamud repository feeds for Stellar Auto Login:

- Global: https://raw.githubusercontent.com/Calamyr/StellarPluginRepo/main/global/repo.json
- China: https://raw.githubusercontent.com/Calamyr/StellarPluginRepo/main/china/repo.json
- Taiwan: https://raw.githubusercontent.com/Calamyr/StellarPluginRepo/main/taiwan/repo.json

Add the feed matching your client, then install Stellar Auto Login in Dalamud. Stellar Launcher adds the appropriate feed when Dalamud is installed; the plugin is installed manually.

Automatic character login currently supports Global only. China and Taiwan builds provide region recognition and configuration and need further in-game validation. Plugin targets remain local to each account; account information is not part of this repository.
